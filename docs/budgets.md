# Budgets & Spend Alerts

To prevent unexpected cloud billing spikes, AI Cost lets you set monthly budgets per project with configurable warning thresholds (50%, 75%, 80%, 90%, 100%).

## How Thresholds Work

- **Normal (< threshold)**: Project spend is well within budget.
- **Warning (>= threshold)**: A warning alert is raised in the dashboard.
- **Exceeded (>= 100%)**: Critical alert is recorded.

*Note: AI Cost does not block production requests automatically unless explicitly configured, ensuring your services remain available.*
